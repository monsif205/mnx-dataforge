    - Parquet export; selected-record / per-dataset backup (only full workspace backup)
    - Automatic scheduled backups; saved filters; date and quality filters in search
    - Write-protection "access history" for evaluation sets (lock/unlock events are logged in the dataset log)
    - Marking records as "intended similarity" in the UI (the engine supports it)
    - Arabic search is token-based after normalization (diacritics, alef/yaa variants folded); no stemming
    - Language is detected by script only (arabic/latin/mixed), not true language identification
    - Dedup/leakage scan the first 50,000 records of a dataset; the report says when that limit applies
    - UI automated tests; device performance measurements; accessibility audit

4. KNOWN RISKS
    - First Gradle build may reveal Kotlin/Compose type errors that could not be detected here.
    - Release APK uses the debug signing key.
    - Liquid glass here is a translucent gradient material with specular edge and soft shadow. It is not
      real backdrop blur/refraction (that was left out to keep rendering cheap on 4 GB devices).
    - Status/navigation bar icon colours follow the selected theme; not checked on a device.

5. FRAMEWORK NOTE

    to match the Monex project rules. No Rust Android UI framework comparison or proof of concept was done.
