- core/src/pdf.rs: PDF text extraction in Rust (object scan, object streams, Flate/ASCIIHex/ASCII85, PNG predictors,
  page tree order, ToUnicode CMaps, WinAnsi/Differences, Form XObjects, paragraph rebuild, de-hyphenation).

- Not done yet: XLSX import, message attachments (file inside an assistant answer). Planned next.

1.0.13 - background installation
- ops/Background.kt: BackgroundService (foreground service, type dataSync, notification with Stop) + BgQueue (queue, status, last report).
  Tasks: Fetch(source) and Resume(unfinished import). Runs the same fetchSource/runJob (checkpointed), so a kill or the Android 15
  ~6h/day dataSync limit (onTimeout) only pauses; "Unfinished imports" resumes later.
- data/Db.kt: Shared.repo(ctx) = one Repo for UI and service (AppState uses it).
- Manifest: FOREGROUND_SERVICE, FOREGROUND_SERVICE_DATA_SYNC, POST_NOTIFICATIONS, <service>.
- UI (Sources): "In background" on each source (not for sources needing an API key: keys are never stored) and on unfinished imports;
  a card with live status, Stop, and the last background report. Notification permission asked on first use.
- Not done: auto-start after reboot, WorkManager scheduling (periodic update checks), Wi-Fi-only / charging-only conditions.
- Kotlin compiled only in CI; never run on a device.

1.0.14 - cleanup, more formats, header
- core/src/cleanse.rs (op "cleanse"): PII masking (email, phone, IPv4, URL), boilerplate lines, repeated lines, record filters
  (min chars, quality, repeated-word share, language). Per record: keep / change / drop with reasons. 3 tests.
- ops/Clean.kt + ui/CleanUi.kt: Cleanup card in the Transfer tab. Preview (nothing changes) or Apply (snapshot "before cleanup" first;
  changed records keep their history, dropped records keep their final content).
- core/src/formats.rs: EPUB (spine order), OpenDocument odt/odp/ods, PPTX (per slide), RTF, Jupyter .ipynb, SRT/VTT subtitles.
  Wired into reader.rs by extension (ZIP containers detected by magic + extension). Real-file tests (LibreOffice odt/rtf, python-pptx).
  100 Rust tests pass. Limits: text only; RTF encodings other than cp1252/unicode escapes are not mapped; ODS/ODP are flattened to text;
  XLS (old binary), DOC and PPT (binary) are NOT supported.
- UI: the page title folds away while scrolling down (only the floating glass icons stay) and returns when scrolling up.
- Kotlin compiled only in CI.

1.0.16 - documents into conversation datasets
- Problem (user log): PDF/DOCX/MD files imported into a conversation dataset were all rejected: "no role labels found".
- Fix (core/src/reader.rs + script.rs doc_chunks): a document with no User:/Assistant: labels is no longer rejected.
  Its text is cut into pieces of at most 6000 chars on paragraph boundaries; each piece becomes an editable conversation with one
  user message and metadata {document, part, parts, unlabeled:true}. Labelled files behave as before.
- Tests: pdf+docx into conversation mode (103 Rust tests pass).
