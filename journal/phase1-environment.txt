DECISION RECORDED (user choice): HYBRID ARCHITECTURE
- UI layer: Kotlin only (Jetpack Compose or plain Android Views), minSdk 35 (Android 15+).
- Banned: Google Play Services, Android System WebView / any WebView.
- Core engine: Rust (no_std not required), called through JNI. Holds storage,
  validation, dedup, import/export, versioning, splits, search.
- Reason: matches the project rule (Kotlin UI only) while keeping the heavy,
  RAM-critical logic in Rust. The original directive said Rust-only; this
  deviation is approved by the user.

CONSEQUENCE
- A real APK cannot be built or installed inside this session:
  no SDK, no NDK, no Android Rust target, and no way to download them.
- What CAN be done here: write and unit-test the full Rust core on the host
  (x86_64), write the Kotlin UI sources and Gradle project files.
- Compiling the APK needs one of: (a) the user's own build machine / CI with
  SDK 35 + NDK + rust target aarch64-linux-android, or (b) network installs
  enabled in account settings (applies to a NEW chat).
- Nothing will be reported as "Verified on device" until it actually is.
